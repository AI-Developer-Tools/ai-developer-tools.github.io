# Project 3: Frontend Development

## Learning Goals

- Learn how to transform development specifications into a working user interface.  
- Learn how to use Figma's AI tools to create mockups.
- Learn how to collaborate with LLMs to generate frontend code, while refining and debugging the output, with a mocked backend.  

## Project Context

In Project 1, you defined requirements and user stories. In Project 2, you expanded some of those stories into detailed development specifications. In Project 3, you will **implement the front end** of your application.  

Begin by creating polished UI/UX mockups in Figma for your user stories. Then, you’ll use those mockups and the development specifications to use LLMs to generate the frontend. Since the backend isn’t fully implemented yet, you will need to mock the backend to simulate functionality.  

The emphasis here is on getting something real and visual, even if it’s only partially functional. By the end of this milestone, you’ll have mockups , a working frontend implementation, and mocked backend to power the interface.  

---

## Deliverables

Choose **two of the three user stories** from your Project 2 development specs to implement at the frontend layer. These must include one independent story and one dependent story. Deliverables are as follows:  

### 1. UI/UX Mockups in Figma  
Create high-fidelity mockups for each of your two chosen user stories.  
   - Include all states of the interface: empty state, loading, error, success, etc.  
   - Annotate your mockups with rationale for major design choices (e.g., navigation flow, component reuse, accessibility).  
   - Either provide links to your mockups or screenshot them in high resolution.    

### 2. Frontend Implementation  
Implement the mockups in code using a popular frontend framework (e.g., React).  
   - Generate code using the LLM based on your Figma designs, user stories, and development specifications.  
   - Include responsive design for at least two screen sizes.  
   - Ensure accessibility compliance with ARIA roles and alt text where appropriate.  
   - Ensure any backend functionality or data is mocked such that the frontend functionality can be demonstrated.
   - Commit your implementation to your GitHub repo.    

### 3. Reflection  
Write a one-page reflection on:  
1. How effective the LLM was in helping generate frontend code.  
2. Where you had to intervene most as a human developer.  
3. How did you test the functionality?
